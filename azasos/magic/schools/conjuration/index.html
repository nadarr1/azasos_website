Conjuration is the third school of magic that exists in Azasos. It focuses on using Magic Energy to create manifestations---or illusions---of real matter. These manifestations can look real when an experienced Conjurer created them. Creativity and photographic memory can be very useful skills for a Conjurer because they have to imagine the things they want to create in great detail to create something believable. Conjurers can use Amethysts to focus their Magic Energy.

Static Manifestations:
creating non-moving manifestations is relatively easy, but has limitations in both its believability and the general amount of use cases.
Moving Manifestations:
while harder to create, once mastered, the movement added to these manifestations can make them more believable and can open up more opportunities to use them.
